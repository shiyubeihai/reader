# 北冥有鱼

单文件网页阅读器，可装到手机或桌面当 App 用（PWA）。没有后端，不上传任何内容。

**当前版本：v2.4.3**

## 功能

- **格式**：TXT、EPUB 2/3、MOBI6、DOCX、HTML
- **排版**：横排 / 竖排，字号、行距、页边距、亮度可调
- **字形**：繁体 / 简体切换
- **字体**：中文思源宋体、思源黑体、江城圆体；西文 Literata、Newsreader、Source Serif 4、PT Serif、PT Sans，覆盖拉丁与西里尔
- **纸张**：12 种背景，含宣纸、云鲸、春華、夏炎、秋实、冬雪
- **书架**：最多 8 个，列表 / 网格两种排列，书籍可改封面、重命名
- **阅读**：书签、全文搜索、进度记忆、阅读计时
- **日历**：按天统计阅读时长，标注农历、干支、节气与纪念日
- **音乐**：导入 mp3 / WAV / FLAC 边读边听，内置湖浪、果壳铃、烛火三条白噪音

## 安装

打开 `https://<你的用户名>.github.io/reader/`

- **Chrome / Edge**：地址栏右侧的安装图标
- **iPhone**：Safari 分享菜单 → 添加到主屏幕

书架、书籍、阅读进度与音乐都存在浏览器本地，换设备或清缓存会丢失。
